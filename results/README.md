# Resultados

`netlist/alu_sintetizada.v` es la netlist exportada por DC. `gds/alu_jose_GF150_routed.gds` es el layout exportado desde el bloque routed de ICC2. Las métricas y limitaciones se describen en `../docs/informe_final.md`.

El checkpoint NLIB final no se incluye: contiene vistas de bibliotecas físicas sujetas a licencia y puede ser demasiado grande para GitHub. Entrégalo sólo por el medio autorizado por el curso y tras comprobar las condiciones de distribución del PDK.
